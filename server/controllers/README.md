# Controllers
Handles incoming requests and returns responses for API endpoints:
- authController.js (Register, Login, Google OAuth)
- skillController.js (Create, list, search skills)
- requestController.js (Send, accept, reject connection requests)
- connectionController.js (List active partner connections)
- meetingController.js (Create, validate, end 30-min meetings)
- messageController.js (Fetch and persist chat messages)
- adminController.js (Admin platform statistics)
